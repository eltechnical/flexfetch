## Note
This project has been discontinued and the successor is eltechnical/ultrafetch, this is a point of no return and a successor was needed in order to keep up with the lines of code, the new version will have less bash script and more C script.
I am working very hard in order to keep up with dylanaraps/neofetch's thousands of lines of bash script, I was unable to keep up and decided to discontinue this project in order to make a successor, again, the successor is eltechnical/ultrafetch.
The fresh start of a new fetch utility can help me get more time into what I can actually need to do to my projects and fix the problems with the original dylanaraps/neofetch. This is not a step back, this is evolution adjusting to the difficulties of bash script.
## The Future
All of the project's potential future updates will instead happen on eltechnical/ultrafetch for further efficiency and better workloads. eltechnical/ultrafetch will have more hardware-software integration due to the use of C and will increase the overall performance of the fetch utility by a big number.
